# Portal de Citas - Clinica Belen

Aplicacion web para agendar, consultar, confirmar, reprogramar y cancelar citas medicas de la Clinica Belen.

## Stack

- Next.js App Router + TypeScript
- React
- Prisma
- Supabase Auth/PostgreSQL
- Zod
- Vitest y Playwright

## Flujo replicado

- Inicio con acciones principales.
- Registro de nuevo paciente.
- Identificacion de paciente.
- Seleccion de especialidad.
- Seleccion de profesional.
- Seleccion de fecha y horario.
- Confirmacion y cita agendada.
- Consulta y detalle de cita.

## Scripts

```bash
npm run dev
npm run build
npm test
npm run test:e2e
npm run db:migrate
npm run db:deploy
npm run db:seed
```
